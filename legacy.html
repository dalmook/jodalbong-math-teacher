키는 이 탭의 메모리에만 보관하고 OpenAI에 직접 전송해요. GitHub·서버·브라우저 저장소에 저장하지 않아요. 브라우저 직접 키 입력은 본인 임시 테스트용이며 운영용 보안 구조가 아니에요.

어린이 실사용 전에는 별도 안전·개인정보 설계가 필요해요. 이 버전에 어린이 음성·이름·전화번호를 입력하지 마세요. store:false는 Zero Data Retention 승인을 대신하지 않아요.

테스트 방식과 제한

정답 채점은 앱이 하고, GPT는 제한된 지도 행동만 고릅니다. GPT가 만든 임의 문장은 표시하거나 읽지 않습니다. 풀기 전에는 최종 답을 주지 않지만, 중간 단계의 힌트는 제공합니다.

실시간 자유대화 모델이 아닌 음성인식 + 분류 + TTS 구조입니다. 마이크는 누를 때만 켜지고, 음성 인식 결과를 확인한 뒤 전송합니다. 녹음 원본은 인식을 위해 먼저 OpenAI에 전달됩니다.

앱은 개인정보를 저장하지 않습니다. API 제공자의 기본 보관정책은 별도이며 최대 30일 보관 등이 적용될 수 있습니다. 탭이 숨겨지면 녹음·재생을 중단합니다. 15분 미사용 시 키를 지웁니다. 세션 요청 120회 제한은 서버 비용 상한이 아닙니다.
