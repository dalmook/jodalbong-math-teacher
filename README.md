# 일타강사 조달봉 · 실시간 산수 교실

**v0.2.0 · 2026-09-13 · 성인 본인 테스트용**

실행: https://dalmook.github.io/jodalbong-math-teacher/?v=0.2.0

## 이번 변경: 버튼형 학습지에서 실제 음성 대화로

키 입력 및 성인 전송 동의 후 **연결하고 대화 시작** 한 번이면 됩니다. 브라우저의 최초 마이크 허용은 필요합니다. 그 뒤에는 녹음 시작/끝, 인식 글 확인, 전송, 정답 제출, 다음 문제 버튼을 누르지 않습니다.

`모르겠어요` → 작은 질문. `2요` → 앱 채점 및 다음 단계. `13이요` → 앱 정답 확인. `다음 문제` → 다음 칠판. `곱셈 하자` → 연산 변경. `아니, 12라고 했어` → 직전 오인식 채점 되돌리기. `그만할래` → 마이크/연결 종료.

손으로 누르는 기본 제어는 수업 시작, 쉬기/재개, 끝내기뿐입니다. 글 입력은 접힌 보조 기능입니다. 막힌 음성 자동재생은 브라우저 제약으로 `소리 켜기`를 한 번 눌러야 할 수 있습니다.

## 음성 구조

기본 `gpt-realtime-2.1-mini`를 사용하는 **WebRTC 실시간 speech-to-speech**입니다. 기존 STT → 문장 분류 → 별도 TTS 방식이 아닙니다. Semantic VAD(medium), 자동 응답, 발화 중 끼어들기를 활성화합니다. 마이크는 수업 중 계속 켜져 있으며 대화가 끝나면 꺼집니다.

기본은 별도 음성인식 모델을 호출하지 않습니다. 선택 설정인 `내 말 자막`을 켜면 `gpt-4o-mini-transcribe` 전사 비용이 추가됩니다. 응답 음성의 자막은 기본 표시됩니다. 계정의 모델 접근 문제가 있을 때만 사용자가 `기존 gpt-realtime-mini`를 직접 고를 수 있습니다. 비싼 모델로 자동 전환하지 않습니다.

입력한 키로 OpenAI `/v1/realtime/client_secrets`를 호출하여 짧은 수명의 임시 키를 받고, `/v1/realtime/calls`의 SDP 교환에는 임시 키를 사용합니다. 원래 API 키를 GitHub나 별도 중계 서버로 보내지 않습니다. **클라이언트 직접 키 입력은 본인 임시 테스트용이고, 운영용 키 보안 구조가 아닙니다.**

## 선생님과 앱의 역할

선생님은 이제 자유롭게 말하고 맥락을 따라 설명합니다. 단답형 지도 행동만 분류하던 v0.1과 다릅니다. 다만 채점·문제 번호·작은 단계·다음 칠판 변경은 `lesson.js`의 검증된 함수만 실행합니다. 정답 전 상태에서는 최종 답/해설을 도구 결과에 넣지 않습니다. 잘못된 도구 인자, 오래된 문제 ID, 중복 호출, 완료된 문제 재채점은 차단합니다.

**한계:** 실시간 모델은 문제를 스스로 계산할 수 있습니다. 정답 선공개 금지 지침과 상태 검증을 넣었어도, 생성 음성의 정답 유출·오인식·잘못된 설명을 완전히 차단하지는 못합니다. 자막은 생성 후 오는 정보이므로 음성이 이미 들린 뒤의 탐지는 사전 차단이 아닙니다. 이 버전은 대화 UX 검증용이며 시험 보안·랭킹 시스템이 아닙니다.

## 데이터·안전·비용

성인이 본인 목소리로 테스트하세요. 실제 어린이 음성이나 개인정보를 넣는 서비스로 공개하지 마세요. 어린이 서비스에는 연령에 맞는 보호장치, 데이터 처리 설계와 해당되는 Zero Data Retention 요건 등의 별도 검토가 필요합니다. 보호자 동의나 `store:false`만으로 ZDR을 충족하지 않습니다.

키·대화는 localStorage, sessionStorage, 쿠키, 서버, 로그에 저장하지 않습니다. 현재 탭 메모리만 사용합니다. 실시간 마이크 데이터는 연결 중 OpenAI로 직접 전달됩니다. 앱의 미저장과 OpenAI의 데이터 보관 정책은 별개입니다.

기본 10분(설정 5/10/20분), 사용자 발화 없는 시간 120초, 응답 160회에 자동 종료합니다. 탭 이탈/새로고침/종료 시 마이크 트랙과 연결을 정리하고 진행 중 인증 요청도 취소합니다. 종료 버튼·이탈 시 키를 지우며, 비활성 키는 15분 후 지웁니다. 쉬기 버튼은 마이크와 자동응답을 끕니다. 제한은 서버 강제 과금 상한이 아닙니다. API 사용량은 OpenAI 대시보드로 확인하세요.

## 검증 범위

- Node 단위/모의 테스트 **48개 통과**: 기존 31개 + 실시간 수업/전송 제어 17개. `npm test`.
- Chromium 오프라인 UI/모의 WebRTC 테스트 **29개 통과**: 360/390/430/1440 너비, 키 입력 후 자동연결, 손 안 대는 작은 단계, 오인식 정정, 다음 문제, 종료/권한 오류 후 마이크 정리.
- 이 환경의 브라우저 탐색이 관리자 정책으로 막혀 HTML/CSS와 묶은 컨트롤러를 오프라인으로 렌더링했습니다. fetch, WebRTC, 마이크, 오디오 재생은 모의 객체입니다. **실제 OpenAI 유료 통화, 실제 휴대폰/iPhone/Safari, 배포 출처 CSP/ES module 네트워크 경로와 실제 음성 품질은 미검증**입니다.
- 상세 결과: `evidence/live-browser-results.json`. 단위 테스트 코드: `tests/live.test.js`. 배포 후 실제 HTTP 파일 및 Actions 상태는 별도로 확인합니다.

## 파일과 이전 버전

새 기본 화면: `index.html`, `live.css`, `live.js`. 실시간 전송: `realtime.js`. 수업 상태/도구: `lesson.js`. 기존 계산 엔진 `engine.js`는 수정하지 않았습니다. v0.1 버튼형은 `legacy.html`로 보존했고 기존 `app.js`, `api.js`, `style.css`도 그대로입니다. GitHub Pages가 main 루트를 배포합니다.

변경 범위는 이 테스트 저장소뿐입니다. 점핑배틀·달봉 퀴즈섬 운영 저장소와 원격 PC 작업폴더에는 변경하지 않았습니다.
